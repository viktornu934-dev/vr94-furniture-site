САЙТ ТОО «ВР-94» — ВЕРСИЯ С КАБИНЕТОМ ДЛЯ ФОТОГРАФИЙ

ВАЖНО: сайт и учётные записи должны принадлежать вам. Создавайте GitHub и Cloudflare под СВОИМИ аккаунтами. Пароль и коды подтверждения никому не передавайте.

СТРУКТУРА
- site/index.html — главная страница
- site/styles.css — дизайн и мобильная версия
- site/script.js — мобильное меню, фильтры портфолио, увеличение фотографий
- site/data/projects.json — проекты для портфолио
- site/data/site.json — контакты и график
- site/media/portfolio/ — фотографии проектов
- .pages.yml — настройка Pages CMS для добавления фото без редактирования кода

КАК СОХРАНИТЬ ПРАВА ВЛАДЕЛЬЦА И ДОБАВЛЯТЬ ФОТО
1. Войдите в https://github.com/ под СВОИМ аккаунтом.
2. Создайте репозиторий, например vr94-furniture-site. Можно выбрать Private, чтобы исходники не были открыты всем.
3. Загрузите содержимое этой папки в репозиторий, включая скрытый файл .pages.yml и папку site.
4. В Cloudflare откройте Workers & Pages → Create application → Pages → Connect to Git и подключите СВОЙ GitHub. Выберите созданный репозиторий.
5. Для настроек сборки укажите Build command: exit 0. Build output directory: site. Затем разверните сайт.
6. Откройте https://app.pagescms.org/ и войдите через GitHub. Установите/разрешите приложение Pages CMS доступ к вашему репозиторию.
7. Выберите репозиторий vr94-furniture-site. Файл .pages.yml уже настроен: в левой панели появится «Портфолио — фотографии проектов».
8. Откройте портфолио, добавьте запись, укажите название и категорию, загрузите фото, добавьте описание и сохраните. Pages CMS сохранит фото и запись в ВАШ GitHub.
9. Cloudflare Pages автоматически опубликует обновление после коммита. Может понадобиться немного подождать завершения публикации.

ПОЧЕМУ НУЖЕН ИМЕННО GITHUB-ПОДХОД
Pages CMS редактирует файлы репозитория и загружает фотографии в него. Поэтому права владельца сохраняются за вашим GitHub-аккаунтом; Cloudflare публикует сайт из вашего репозитория. Кабинет редактирования находится отдельно на app.pagescms.org, а не внутри публичной страницы.

ПЕРВАЯ ФОТОГРАФИЯ
Первая присланная фотография спальни включена как первый элемент портфолио без ретуши. Второй снимок — скриншот Instagram с интерфейсом и строительной обстановкой — не включён на публичную страницу.

ЗАЯВКИ И КОНТАКТЫ
В сайт внесены указанные адрес, график и Instagram. Телефон не придуман. Для настоящей формы с сохранением заявок нужно дополнительно подключить обработчик или CRM; текущая версия ведёт клиентов в Instagram.

ЛОКАЛЬНЫЙ ПРОСМОТР
Открытие index.html двойным кликом может не загружать JSON из-за ограничений браузера. Проверяйте опубликованную версию Cloudflare Pages или используйте локальный сервер.
